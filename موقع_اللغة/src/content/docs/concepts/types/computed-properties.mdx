## ٢‑٨ · صفاتٌ يحسبها المترجم ولا تُكتب

| الصفة | تثبت للنوع حين | مصدرُها |
|---|---|---|
| قابلٌ للنسخ | لا يحوي موردًا ولا `مشترك<ن>`، إلّا عبر `تابع<ن>` | ل٥، وق‑٣ م‑أ |
| قابلٌ للنسخ بالبتّات | كلُّ حقوله كذلك | كلفةُ النسخ |
| يحوي مشتركًا | أحدُ حقوله `مشترك` | ل١٠ |
| يُرجِع استعارةَ حقل (للدالّة) | طريقةٌ غيرُ معدِّلة تُرجِع حقلًا، أو ناتجَ ٧‑أ من طريقةٍ أخرى، على كلّ طرق الإرجاع | ق‑٣، الموضع ٧‑أ |
| محصورٌ بخيط الواجهة | أحدُ حقوله `@حالة` | ل٩ |
| بصمةُ التخطيط | تُحسب من التصريح وحده، وتسري إلى من يحويه | ق‑٢ |
| بصمةُ الواجهة | التوقيعاتُ **والصفاتُ المحسوبة أعلاه** | ق‑٢ |

**والمشتقّاتُ التلقائيّة:** المساواةُ والتجزئةُ والعرضُ تُشتقّ إذا دعمتها كلُّ الحقول، و`عشري` بلا تجزئة.
**والتسلسلُ (JSON) يُطلب بإعلانٍ صريح،** لأنّه التزامٌ بصيغةٍ خارجيّة. والاشتقاقُ كلّه يجري وقتَ الترجمة (ل١٤).
