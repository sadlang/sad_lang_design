## القرار

| المسألة | القرار |
|---|---|
| **الترخيص** | **ترخيصُ LLVM نفسُه:** Apache-2.0 مع استثناء LLVM |
| **شرطُ المساهمة** | **إقرارُ DCO في كلّ إيداع،** لا اتّفاقيّةٌ موقَّعة. **ولا يضعه إلّا إنسانٌ راجع العرّافاتِ ويتحمّل المسؤوليّة،** وإن كتب الشفرةَ الذكاءُ الاصطناعيّ (عُدِّل ٢٠٢٦-١٠-١٧: كان «قرأ الشفرة») |
| **Unicode** | **إصدارٌ مثبَّت،** يُرقّى عمدًا مع اختبارات المطابقة الرسميّة، ومعه إشعارُ رخصته |
| **توحيدُ الهمزة** | **جدولٌ منفصلٌ من ك‑١،** لأنّه سياسةُ ص لا من Unicode |

(ق‑٨، ٢٠٢٦-١٠-١٧)
</قسم>

<قسم حالة="معتمد">
## العلّة

1. **ترخيصُ LLVM نفسُه،** فلا تعارضَ بين الترخيصين.
2. **الإقرارُ سطرٌ في الإيداع،** والاتّفاقيّةُ الموقَّعة تنفّر الطلّاب.
3. **الذكاءُ الاصطناعيّ لا يوقّع،** وإنّما يقرّ إنسانٌ يتحمّل مسؤوليّة ما يقدّمه، ومراجعتُه مراجعةُ العرّافات لا الشفرة.
4. **إن اختلطت سياسةُ الهمزة بجداول Unicode** أفسدتها ترقيتُه.
</قسم>
