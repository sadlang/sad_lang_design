---
title: المترجم
description: أنظمةُ مترجم ص الداخليّة، وقراراتُ تطويره، ومعاييرُ شفرته وجودتها.
---

**هذا القسمُ لمن يكتب مترجمَ ص،** لا لمن يكتب بص. ففيه:

| | ما فيه |
|---|---|
| **قراراتُ التطوير** | المحرّك ووضعُ التطوير، ولغةُ المترجم وخلفيّتُه |
| **الأنظمةُ الداخليّة** | نظامُ الأخطاء، والعرضُ في الطرفيّة، والتمثيلُ والذاكرة، والخلفيّة |
| **معاييرُ الشفرة والجودة** | سياسةُ الأمان، ودليلُ الأسلوب، والتكاملُ المستمرّ |

- **الدليل** للمساهم الجديد: كيف يبني المترجمَ ويبدأ.
- **المرجع** للقرارات، وحالةُ كلّ قسمٍ فيه ظاهرة.
