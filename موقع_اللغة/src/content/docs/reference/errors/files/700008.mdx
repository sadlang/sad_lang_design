## متى يظهر

في الملفّ بايتٌ لا يصحّ في UTF-8. وأشيعُ سببٍ ملفٌّ حُفظ بترميز UTF-16 أو بصفحة ترميزٍ قديمة.

```text
خطأ[700008 ملفات.ترميز_خاطئ]: الملفّ «{path}» ليس بترميز UTF-8: البايتُ عند الإزاحة {offset} لا يصحّ فيه
```

## مثالٌ يخطئ

```text
$ sad تالف.ص
خطأ[700008 ملفات.ترميز_خاطئ]: الملفّ «تالف.ص» ليس بترميز UTF-8: البايتُ عند الإزاحة ١٢ لا يصحّ فيه
```

## مثالٌ يصحّ

```text
$ sad مرحبا.ص
```

## العلّة

ملفُّ المصدر بترميز UTF-8 (ق‑١٠). احفظ الملفَّ في المحرّر بترميز UTF-8. والإزاحةُ من أوّل الملفّ كما على القرص.
