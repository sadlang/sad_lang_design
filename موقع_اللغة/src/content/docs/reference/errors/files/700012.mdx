## متى يظهر

المسارُ أنبوبٌ مسمّى أو جهازٌ أو مقبس، لا ملفٌّ على القرص.

```text
خطأ[700012 ملفات.ليس_ملفا_عاديا]: «{path}» ليس ملفًّا عاديًّا
```

## مثالٌ يخطئ

```text
$ sad جهاز.ص
خطأ[700012 ملفات.ليس_ملفا_عاديا]: «جهاز.ص» ليس ملفًّا عاديًّا
```

## مثالٌ يصحّ

```text
$ sad مرحبا.ص
```

## العلّة

الأنبوبُ قد لا ينتهي، والجهازُ مثلُ `/dev/zero` لا ينتهي أبدًا، فيعلق المترجمُ أو تنفد ذاكرتُه.
