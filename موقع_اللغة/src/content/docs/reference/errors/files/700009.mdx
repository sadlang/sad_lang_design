## متى يظهر

في الاسم محرفٌ يرفضه نظامُ التشغيل، مثلُ `<` أو `?` على Windows.

```text
خطأ[700009 ملفات.اسم_غير_صالح]: «{path}» ليس اسمَ ملفٍّ صالحًا في نظام التشغيل
```

## مثالٌ يخطئ

```text
$ sad ما<.ص
خطأ[700009 ملفات.اسم_غير_صالح]: «ما<.ص» ليس اسمَ ملفٍّ صالحًا في نظام التشغيل
```

## مثالٌ يصحّ

```text
$ sad ما.ص
```

## العلّة

أسماءُ الملفّات يحكمها نظامُ التشغيل لا المترجم.
