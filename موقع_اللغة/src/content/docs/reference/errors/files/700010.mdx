## متى يظهر

برنامجٌ آخرُ فتح الملفَّ ومنع غيرَه من قراءته (Windows).

```text
خطأ[700010 ملفات.مقفل]: الملفّ «{path}» مقفلٌ ببرنامجٍ آخر، فلا يُقرأ
```

## مثالٌ يخطئ

```text
$ sad مرحبا.ص
خطأ[700010 ملفات.مقفل]: الملفّ «مرحبا.ص» مقفلٌ ببرنامجٍ آخر، فلا يُقرأ
```

## مثالٌ يصحّ

بعد أن يُغلق البرنامجُ الآخرُ الملفّ:

```text
$ sad مرحبا.ص
```

## العلّة

أغلق البرنامجَ الذي يقفل الملفّ، ثمّ أعد الترجمة.
