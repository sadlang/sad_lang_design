## متى يظهر

فشلت القراءةُ لسببٍ لا خطأَ له في الفهرس، ويتبعه نصُّ نظام التشغيل في الملاحظة 700011.

```text
خطأ[700007 ملفات.فشل_القراءة]: تعذّرت قراءةُ الملفّ «{path}»
```

## مثالٌ يخطئ

```text
$ sad مرحبا.ص
خطأ[700007 ملفات.فشل_القراءة]: تعذّرت قراءةُ الملفّ «مرحبا.ص»
ملاحظة[700011 ملفات.نص_النظام]: قال نظامُ التشغيل: …
```

## مثالٌ يصحّ

أصلح ما يذكره نظامُ التشغيل في الملاحظة، ثمّ أعد الترجمة:

```text
$ sad مرحبا.ص
```

## العلّة

ما لا يُعرف سببُه يبقى بعنوانٍ عربيّ، ونصُّ النظام في ملاحظةٍ تتبعه، لأنّه يختلف بين المنصّات واللغات (ق‑١٠).
