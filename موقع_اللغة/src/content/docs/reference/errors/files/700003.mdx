## متى يظهر

امتدادُ الملفّ ليس `.ص`، أو لا امتدادَ له.

```text
خطأ[700003 ملفات.امتداد_خاطئ]: «{path}» ليس ملفَّ مصدر: امتدادُ ملفّ المصدر «.ص»
```

## مثالٌ يخطئ

```text
$ sad مرحبا.txt
خطأ[700003 ملفات.امتداد_خاطئ]: «مرحبا.txt» ليس ملفَّ مصدر: امتدادُ ملفّ المصدر «.ص»
```

## مثالٌ يصحّ

```text
$ sad مرحبا.ص
```

## العلّة

ملفُّ المصدر يُعرف بامتداده `.ص` (ق‑١٠)، فلا يقرأ المترجمُ ملفًّا آخرَ ظنًّا أنّه شفرةُ ص.
