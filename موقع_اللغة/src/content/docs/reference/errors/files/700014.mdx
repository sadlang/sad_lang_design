## متى يظهر

اسمُ الملفّ «.ص» وحده، بلا اسمٍ قبل الامتداد.

```text
خطأ[700014 ملفات.امتداد_بلا_اسم]: «{path}» امتدادٌ بلا اسم ملفّ
```

## مثالٌ يخطئ

```text
$ sad .ص
خطأ[700014 ملفات.امتداد_بلا_اسم]: «.ص» امتدادٌ بلا اسم ملفّ
```

## مثالٌ يصحّ

```text
$ sad مرحبا.ص
```

## العلّة

نظامُ التشغيل يعدّ «.ص» اسمَ ملفٍّ مخفيٍّ بلا امتداد. فلا يُقرأ، ويُسمّى الملفُّ باسمٍ قبل امتداده.
