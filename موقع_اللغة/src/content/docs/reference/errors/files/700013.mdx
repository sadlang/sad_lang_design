## متى يظهر

حجمُ الملفّ يتجاوز ما تسعه إزاحاتُ المواضع.

```text
خطأ[700013 ملفات.كبير_جدا]: الملفّ «{path}» أكبرُ من {limit} بايت
```

## مثالٌ يخطئ

```text
$ sad ضخم.ص
خطأ[700013 ملفات.كبير_جدا]: الملفّ «ضخم.ص» أكبرُ من ٤٢٩٤٩٦٧٢٩٥ بايت
```

## مثالٌ يصحّ

```text
$ sad مرحبا.ص
```

## العلّة

المواضعُ تُخزَّن بإزاحة البايت في الملفّ (ق‑٦ و)، وعرضُها ٣٢ بتًّا. فالملفُّ أكبرُ منها لا يُشار إلى موضعٍ فيه. قسّم الشفرةَ على ملفّات.
