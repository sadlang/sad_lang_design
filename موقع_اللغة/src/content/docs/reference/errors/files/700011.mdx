## متى يظهر

ملاحظةٌ تتبع 700007، فيها نصُّ نظام التشغيل كما كتبه.

```text
ملاحظة[700011 ملفات.نص_النظام]: قال نظامُ التشغيل: {detail}
```

## مثالٌ يخطئ

لا تظهر وحدها، بل بعد خطأ 700007:

```text
$ sad مرحبا.ص
خطأ[700007 ملفات.فشل_القراءة]: تعذّرت قراءةُ الملفّ «مرحبا.ص»
ملاحظة[700011 ملفات.نص_النظام]: قال نظامُ التشغيل: …
```

## مثالٌ يصحّ

حين تنجح القراءةُ فلا خطأَ ولا ملاحظة:

```text
$ sad مرحبا.ص
```

## العلّة

نصُّ النظام لا يدخل عنوانَ الخطأ، لأنّه ليس عربيًّا ويختلف بين المنصّات (ق‑١٠).
