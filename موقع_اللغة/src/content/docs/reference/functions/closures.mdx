## ٢‑١٢ · المغلَقات: الملتقَطُ لا يُعدَّل

تعديلُ متغيّرٍ ملتقَطٍ داخل مغلَقٍ **خطأُ ترجمة**، إلّا أن يكون `@حالة` أو مقبضَ `مشترك`.

```ص
متغير العداد = ٠
عند_النقر { العداد += 1 }
# ⛔ المغلَقُ يعدّل نسخةً من العداد (الموضع ٦)؛ استعمل @حالة أو مشترك
```

**العلّة:**
- **يحوّل علّةً صامتة** (س٢: «يعدّل نسخةً… فلا تتغيّر الشاشة») إلى رسالةٍ تعلِّم.
- **يتّسق مع س٢:** الحكم ٤ يسمح للمغلَقات المكتوبة داخل المكوّن بكتابة `@حالته`، والحكم ٣ يجعل الكتابةَ عبر
  المقبض.
- **يبسّط المنفّذ:** بيئةُ المغلَق ثابتة، فاستدعاؤه ليس مدّةَ كتابةٍ أبدًا، ولا يحتاج نوعُ الدالّة وسمَ
  «استدعاءٍ معدِّل».
- **سابقتُه:** الالتقاطُ بالنسخ في ++C ثابتٌ ما لم يُكتب `mutable`.
</قسم>

## ٢‑١٣ · قيمُ الدوالّ لا تُقارَن

قيمُ الدوالّ لا تُقارَن بـ`==`، لأنّ وضعَ التطوير يكرّر النسخةَ المخصّصة في كلّ وحدة، والإصدارُ يدمجها. فعنوانُ
الدالّة يختلف بين الوضعين، والمقارنةُ تكسر بوّابةَ التكافؤ (ق‑٢).
</قسم>
