# موقع توثيق لغة ص

هيكلُ الموقع، وأكثرُ صفحاته «يُكتب لاحقًا». وفي رأس كلّ صفحةٍ مشتقّة حقلُ `مصدر` يذكر مصدرَ مادّتها من جذر المستودع، ويفحصه `tools/check_sources.py`.

**أُنشئ هذا الموقع من «الموقع/» (٢٠٢٦-١١-١٩):** المحورُ الأوّل القارئ، والثاني الموضوع.

## القرارات

قرارات الموقع (التصميم، والحالات، والأقسام، والروابط) في [`حوكمة/قرارات_الموقع.md`](../حوكمة/قرارات_الموقع.md). وكيف يُكتب المستودع كلّه في [`حوكمة/اصطلاحات_المستودع.md`](../حوكمة/اصطلاحات_المستودع.md).

## التشغيل

```
npm install       # مرّةً واحدة
npm run dev       # خادمُ تطويرٍ على http://localhost:4321/sad_lang_design/
npm run build     # يبني الموقع في dist/
npm run preview   # يعرض المبنيّ
npm run check     # فحصُ الأنواع (astro check)
```

يحتاج Node 22.19 أو أحدث (`.nvmrc`).
- **الموقعُ منشورٌ على GitHub Pages:** https://sadlang.github.io/sad_lang_design/ ، يبنيه `.github/workflows/pages.yml` من `main` بعد كلّ دفعٍ يغيّر الموقع (قرارات الموقع، القرار ٢٤).
- **والعنوانُ واسمُ المستودع** (`SITE` و`BASE`) في `src/lib/site.mjs` وحده. **فكلُّ رابطٍ داخليٍّ في المحتوى نسبيّ،** لا يبدأ بـ`/`، إلّا رابطَ صفحة ٤٠٤.

## الهيكل

```

  learn/                        تعلّمُ ص: مسارٌ واحدٌ بالترتيب، بلا حالات

    types/                      الاستنباط · أُسَرُ الملكيّة · الصفاتُ المحسوبة · قائمةُ الأنواع

src/lib/decisions.mjs           القراراتُ التي تملكها الصفحات

scripts/check-search.mjs        فحصُ توحيد الهمزات والتشكيل في البحث، بعد كلّ بناء
scripts/check-external.mjs      فحصُ أنّ الموقع لا يحمّل شيئًا من خادم آخر (قرارات الموقع، القرار ٢٠)، بعد كلّ بناء
scripts/check-links.mjs         فحصُ أنّ كلَّ رابطٍ داخليٍّ تحت عنوان الموقع ويصل (قرارات الموقع، القرار ٢٤)، بعد كلّ بناء
scripts/count.mjs               عددٌ ومعدودُه بالعربيّة، لرسائل الفحوص
src/lib/site.mjs                عنوانُ الموقع المنشور واسمُ المستودع: المصدرُ الوحيد

src/lib/ec-verdict.mjs          رأسُ كتلة شفرة ص وحكمُ المترجم

src/routeData.ts                يضع شارةَ حالة الصفحة في القائمة الجانبيّة
src/styles/theme.css            الألوانُ والخطوط للوضعين
```

- **صفحةٌ جديدة:** ملفٌّ بامتداد `mdx` في مجلّد مجموعتها. تظهر في القائمة وحدها، ويُرتَّب موضعُها بـ`sidebar.order` في رأس الملفّ.
  - **إن ملكت قرارًا** أعلنته في رأسها: `يملك: ["ق‑٤/٢‑٢"]`، وأضفته إلى `src/lib/decisions.mjs` إن كان جديدًا.
  - **ويفشل البناء** إن ملكت صفحتان قرارًا واحدًا، أو بقي قرارٌ بلا صفحة، أو أعلنت صفحةٌ قرارًا ليس في القائمة.
- **قسمٌ أو مجموعةٌ جديدة:** في `src/lib/systems.mjs` وحده، ثمّ أنشئ مجلّدها. فتظهر في القائمة الجانبيّة وفي بطاقات الصفحة الرئيسيّة.
  - **`reader`:** لمن القسم، ويظهر في بطاقته.
  - **`statusful`:** صفحاتُه تحمل الحالات: `true` للقسم كلّه، أو مسارٌ فرعيٌّ فيه (في المترجم: `reference`).
  - **`groups`:** إن وُجدت قُسّم القسمُ مجموعاتٍ، كلٌّ منها مجلّدٌ فرعيّ، وللمجموعة مجموعاتٌ أيضًا. ومدخلُ القسم `index.mdx` يبقى فوقها.

## مكوّنات الكتابة

````mdx
import { قسم, شارة, ستتعلم, جرب, خلاصة, قيد_النقاش } from '~/components';

<قسم حالة="معتمد">
## عنوان القسم
…
</قسم>

```ص حكم=تترجم
متغير س = ٥
```

```ص حكم=خطأ
رقمي س = ٥٫٠
```

نصٌّ فيه <شارة حالة="مقترح" /> داخل السطر.

<ستتعلم>…</ستتعلم>   <جرب>…</جرب>   <خلاصة>…</خلاصة>
<قيد_النقاش مرجع="/concepts/ownership/rules-and-invariants/" />
````

- **قيم `حالة`:** `معتمد` · `مقترح` · `مؤجل` · `مفتوح` · `لم_يعالج`. أيُّ قيمةٍ غيرها تُوقف البناء برسالةٍ تذكر القيمَ المسموحة.
- **`<قسم>` للصفحات التي تملك قرارات.** في «تعلّم ص» ودليل المترجم يوقف البناء برسالةٍ تقول: استعمل `<قيد_النقاش>`.
- **كتلةُ شفرة ص:**
  - رأسُها «شفرة ص»، وأرقامُ أسطرها على اليمين، وزرُّ النسخ على اليسار.
  - **`حكم=`** يضع الحكمَ في رأسها، وقيمتُه `تترجم` أو `خطأ`. ويُكتب رمزُ الخطأ بعده إن عُرف: `حكم=خطأ:200014` (ق‑٦).
  - **عنوانٌ آخر:** `title="…"`. **ولإطفاء الأرقام:** `showLineNumbers=false`.
  - **خرجُ المترجم** يُكتب ```` ```خرج ````: نصٌّ من اليمين بلا تلوينٍ ولا أرقام أسطر.
- **ما لا يُحسب حالةً:** `<قسم>` داخل كتلة شفرة، أو داخل شفرةٍ سطريّة، أو في تعليق.
- **ما يحدث آليًّا:** أقسامُ `<قسم>` تُعدّ في «حالة الصفحة» أعلاها. والضغطُ على حالةٍ هناك يخفّت أقسامها. وشارةُ الصفحة في القائمة الجانبيّة تُحسب من أقسامها.
