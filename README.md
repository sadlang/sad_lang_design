# قواعد لغة ص

هذا المستودع **مواصفة لغة ص**: قراراتها، وأنظمتها، وبناها، ومعجم مصطلحاتها، وموقعها.
أمّا شفرة المترجم ومكتبة التشغيل فلها مستودع مستقلّ.

## من أين تبدأ

1. **[`DECISIONS.md`](DECISIONS.md):** الحاكم الوحيد لقرارات اللغة. ما خالفه فهو الخطأ.
2. **[`حوكمة/اصطلاحات_المستودع.md`](حوكمة/اصطلاحات_المستودع.md):** أين يوضع كلّ شيء، وكيف يُسمّى، وما الذي يُفحص.
3. **[`data/glossary.toml`](data/glossary.toml):** المصطلح العربيّ المعتمد لكلّ مفهوم. يُضاف المصطلح هنا قبل أن يُستعمل.

## الخريطة

| المجلّد | ما فيه |
|---|---|
| `DECISIONS.md` | قرارات اللغة ومترجمها، وحالاتها وسجلّها |
| `حوكمة/` | قواعد كتابة المستودع، وقرارات الموقع، ودليل الأسلوب. فهرسها [`حوكمة/اقرأني.md`](حوكمة/اقرأني.md) |
| `data/` | مصادر حقيقة تقرؤها الأدوات (المعجم الآن) |
| `مواصفة/` | تفصيل القرارات: `انظمة/` (الملكيّة والأنواع)، و`بنى/` (التعريفات…)، و`المكتبة/` (لم تُكتب بعد). فهرسها [`مواصفة/اقرأني.md`](مواصفة/اقرأني.md) |
| `موقع_اللغة/` | الموقع (Astro وStarlight)، ودليل بنائه في `README.md` داخله |
| `tools/` | أدوات فحص المستودع، ومولّد صفحة دليل الأسلوب، ومولّدا الخارطتين في `tools/maps/` |

البنية ومواضع كلّ شيء في [الاصطلاحات](حوكمة/اصطلاحات_المستودع.md) §٣. 

## الفحوص

```
python tools/check_links.py    --strict --baseline tools/baselines/broken_links.txt
python tools/check_names.py    --strict --baseline tools/baselines/names.txt
python tools/check_glossary.py --strict
python tools/check_sources.py  --strict
PYTHONIOENCODING=utf-8 python tools/maps/ownership/gen.py
PYTHONIOENCODING=utf-8 python tools/maps/types/gen.py
python tools/gen_style_guide.py
```

والمولّدات تعيد كتابة الخارطتين وصفحة دليل الأسلوب في الموقع، فإن ظهر في `git status` تغيير فيها فأودِعه مع ما غيّرتَه (سير العمل يفشل إن لم يطابق المولَّدُ مصدره).

تحتاج Python 3.11 أو أحدث، بلا مكتبات إضافيّة.
